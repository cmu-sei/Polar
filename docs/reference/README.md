# Reference

The published work Polar's design relies on: papers, standards and the software they describe. Each is cited from the
architecture documents by its key (`sahebolamri2022ascent`), and listed in [`citations.md`](citations.md), with
what it is, where to read it, its licence, why it matters to Polar and which documents cite it. The same entries, for
tools, are in [`references.bib`](references.bib).

Adding a work:

1. An entry in `citations.md` and in `references.bib`, under a key of the first author's surname, the year and a word
   of the title (`cutler2024cedar`). A DOI where the work has one, a stable URL where it does not.
2. A copy in this folder only when its licence allows redistribution (a Creative Commons licence, a public domain or
   open standard), named `<key>.pdf`, with the licence in its entry. A work published under the ACM's (or another
   publisher's) usual terms allows copies "for personal or classroom use" only, and posting it to a server is
   redistribution: cite it by link, and keep any copy outside the repository.
3. The documents that rely on it cite the key, and its entry lists them under "Cited by".
